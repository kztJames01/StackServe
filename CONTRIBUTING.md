# Contributing to StackServe MCP

- If available locally, read `docs/architecture.md`, `docs/research.md` and `docs/PLAN.md` first. They are intentionally untracked; the durable boundary summary is in `README.md`.
- Rust + Python only; no TypeScript.
- Run Rust checks (`cargo fmt`, `cargo clippy`, `cargo test`) and Python checks (`uv run ruff check`, `uv run pytest`) before PR.
- Shared protocol fixtures must pass in both languages.
- Every numeric line must be attributable to a verified service card, region and check date.
- Do not add sponsored placements or affiliate influence.
